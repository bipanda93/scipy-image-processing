# Traitement d'Images avec SciPy ndimage

Pipeline de traitement d'images avec scipy.ndimage - 5 transformations fondamentales.

## Description

Projet explorant 5 transformations d'images avec le module scipy.ndimage.

**Transformations :** Flou gaussien, Sobel, Rotation, Zoom, Filtre uniforme  
**Stack :** Python + SciPy + NumPy + Matplotlib

## Transformations

1. **Flou Gaussien** - Lissage par convolution gaussienne
2. **Sobel** - Détection de contours par gradients
3. **Rotation** - Transformation affine
4. **Zoom** - Rééchantillonnage spatial
5. **Filtre Uniforme** - Lissage par moyenne

## Installation

```bash
pip install -r requirements.txt
```

```bash
python atelier_scipy_ndimage.py
```
